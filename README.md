# SafeChat – וואטסאפ מסונן לילדים

<div dir="rtl">

אפליקציית צ'אט שמתחברת לחשבון הוואטסאפ של הילד ומציגה לו **רק** אנשי קשר וקבוצות שההורה אישר. כל הודעה מצ'אט שלא אושר נחסמת: היא לא מוצגת, לא נשמרת, ואי אפשר לשלוח אליה הודעות.

## איך זה עובד

```
טלפון עם ה-SIM של הילד  ──(מכשיר מקושר)──►  שרת SafeChat  ──►  דפדפן / מסך הבית של הילד
   (נשאר אצל ההורה)                         מסנן לפי רשימה         (רק צ'אטים מאושרים)
```

1. וואטסאפ מותקן על טלפון שנמצא **אצל ההורה** (עם המספר של הילד).
2. שרת SafeChat מתחבר אליו כ"מכשיר מקושר", כמו WhatsApp Web.
3. הילד משתמש רק באפליקציית SafeChat (אתר שאפשר להוסיף למסך הבית) ורואה רק מה שאושר.
4. ההורה מנהל את הרשימה בפאנל הורים (`/admin.html`).

## התקנה

דרוש Node.js 20 ומעלה, על מחשב או שרת שפועל כל הזמן (מחשב ביתי, Raspberry Pi, או שרת בענן).

```bash
git clone <כתובת-הריפו>
cd safe-chat
npm install
PARENT_PASSWORD='סיסמה-חזקה' CHILD_PIN=1234 npm start
```

התקנה אוטומטית על שרת לינוקס חדש (למשל שרת חינמי ב-Google Cloud). הסקריפט מתקין הכל, כולל HTTPS:

```bash
curl -fsSL https://raw.githubusercontent.com/kaplanGitLearn/safe-chat/main/scripts/install.sh | bash
```

או עם Docker:

```bash
docker build -t safe-chat .
docker run -d -p 3000:3000 -v safechat-data:/app/data -e PARENT_PASSWORD='סיסמה-חזקה' -e CHILD_PIN=1234 safe-chat
```

אם לא מגדירים סיסמאות, הן נוצרות אוטומטית בהפעלה הראשונה ומודפסות בטרמינל.

## הגדרה ראשונה

1. פתחו `http://<כתובת-השרת>:3000/admin.html` והתחברו עם סיסמת ההורה.
2. בטלפון של הילד: **הגדרות ← מכשירים מקושרים ← קישור מכשיר**, וסרקו את קוד ה-QR שבפאנל.
3. הוסיפו אנשי קשר לפי מספר טלפון, ואשרו קבוצות מתוך הרשימה.
4. בטלפון של הילד פתחו `http://<כתובת-השרת>:3000`, הכניסו את הקוד, ובחרו "הוספה למסך הבית".

בפאנל יש גם רשימת **"הודעות שנחסמו"**: מי ניסה לכתוב לילד ולא הוצג לו (בלי תוכן ההודעה), עם כפתור אישור מהיר.

## הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | `3000` | פורט השרת |
| `PARENT_PASSWORD` | נוצרת אוטומטית | סיסמת הורה (רק בהפעלה הראשונה) |
| `CHILD_PIN` | נוצר אוטומטית | קוד כניסה לילד (רק בהפעלה הראשונה) |
| `DEFAULT_COUNTRY_CODE` | `972` | קידומת מדינה למספרים שמתחילים ב-0 |
| `DATA_DIR` | `./data` | היכן נשמרים החיבור, ההגדרות וההודעות |

## חשוב לדעת

- **אין API רשמי של וואטסאפ לחשבונות פרטיים.** הפרויקט משתמש בספריית קוד פתוח ([Baileys](https://github.com/WhiskeySockets/Baileys)) שמתחברת כמו WhatsApp Web. זה מנוגד לתנאי השימוש של וואטסאפ, וקיים סיכון (נמוך בשימוש אישי רגיל) שהמספר ייחסם. כדאי להשתמש במספר נפרד לילד ולא במספר של ההורה.
- **לילד אסור שתהיה גישה לאפליקציית הוואטסאפ האמיתית** על המספר הזה, אחרת הוא יעקוף את הסינון. הטלפון עם ה-SIM נשאר אצל ההורה.
- הטלפון הראשי צריך להתחבר לאינטרנט מדי פעם (לפחות פעם ב-14 יום), אחרת וואטסאפ מנתק את המכשירים המקושרים.
- בקבוצה מאושרת הילד רואה את כל ההודעות של כל המשתתפים בקבוצה.
- בגרסה הזו הילד יכול לשלוח רק טקסט. הוא יכול לקבל טקסט ותמונות, ושאר סוגי המדיה מוצגים כתווית (למשל "🎤 הודעה קולית").
- לחיצה ארוכה על הודעה: תגובה (ציטוט), תגובת אימוג'י, סימון בכוכב, העתקה, העברה (רק לצ'אטים מאושרים) ומחיקה (אצלי, או לכולם בהודעות של הילד). הכוכבים נשמרים רק ב-SafeChat ולא מסתנכרנים לטלפון.
- **שיחות וואטסאפ לא נתמכות** (אין לכך תמיכה בספרייה). שיחות וואטסאפ נכנסות נדחות אוטומטית (אחרת היו מצלצלות בטלפון של ההורה), ומשיחה מאיש קשר מאושר הילד מקבל הודעת "שיחה שלא נענתה". כפתור הטלפון בראש השיחה פותח שיחה טלפונית רגילה.
- אם השרת נגיש מהאינטרנט, הפעילו אותו מאחורי HTTPS (למשל Caddy או Cloudflare Tunnel).

## פיתוח

```bash
npm test                               # בדיקות: הסינון וכל פעולות ההודעות
SAFECHAT_FAKE_WA=1 PORT=3000 npm start  # הרצה מקומית עם וואטסאפ מדומה, בלי טלפון
```

מבנה הקוד:
- `server.js`: שרת, API, וחיבור לוואטסאפ
- `lib/filter.js`: חוקי הסינון
- `lib/store.js`: שמירת הגדרות והודעות
- `public/`: מסך הילד (`index.html`) ופאנל ההורים (`admin.html`)
